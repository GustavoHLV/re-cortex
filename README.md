Solução digital de apoio à aprendizagem de pessoas neurodivergentes, com foco em acessibilidade, personalização, feedback e acompanhamento do progresso.

## Prova de conceito do modelo relacional (SQLite)
Teste com dados fictícios, feito em SQLite. Não valida MySQL, Spring Boot nem Spring Data JPA.

1. `01_criar_tabelas_e_consulta.sql`: cria as tabelas, insere os dados e roda a consulta com junções.
2. `02_teste_chave_estrangeira.sql`: deve falhar com `FOREIGN KEY constraint failed`.
3. `03_teste_email_duplicado.sql`: deve falhar com `UNIQUE constraint failed`.

Rodar na ordem 01, 02, 03.
